# Voice Bank — your real writing (episodic memory, raw samples)

> **Template.** Fill this from your own **sent** messages: short, characteristic lines, verbatim, typos kept. Redact third parties' personal data (`[Name]`). Do NOT polish them; the roughness is the voice. Build it during `/brain:writer bootstrap`, then add a line whenever a validated send yields a useful phrase.
>
> Longer validated sends with Claude-vs-you corrections live in `examples.md` (EX-ids). This file holds short raw samples (VB-ids). The description of the voice lives in `style_profile.md`; nothing here is a rule.

## Tag vocabulary

- **type:** `email` · `linkedin-dm` · `linkedin-note` · `linkedin-comment` · `linkedin-post` · `whatsapp` · `slack` · `application-form`
- **tier:** `team` · `peer` · `partner` · `recruiter-warm` · `recruiter-cold` · `industry` · `senior-panel` · `c-suite` · `vendor` · `customer`
- **register:** `rough` · `mid` · `dress-up`
- **source:** `sent-verbatim` (your words, as sent) · `user-edited` (Claude draft you rewrote before sending) · `unsent`
- **date:** ISO date if known; `undated` for bulk corpus pulls

## Selection rule (how the skill uses this file)
Match `type` first, then `tier`, then `register`. Take 3–5 entries. Only `sent-verbatim` and `user-edited` count as voice evidence; `unsent` is never used as an example. If fewer than 3 match, widen `tier` to the adjacent row in the profile's register table before widening `type`.
